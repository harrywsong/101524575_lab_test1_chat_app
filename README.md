# Chat Application

A real-time chat application with user authentication, room-based messaging, and MongoDB persistence.

## Technologies
- Backend: Socket.io, Express, Mongoose
- Frontend: HTML5, CSS, Bootstrap, jQuery

## Features
- User authentication (signup/login)
- Room-based messaging
- Private messaging
- Typing indicators
- Message persistence with MongoDB

## Structure
```
├── models/              # MongoDB schemas
├── public/              # Static files (CSS, JS)
├── views/               # HTML pages
└── server.js            # Main server file
```
